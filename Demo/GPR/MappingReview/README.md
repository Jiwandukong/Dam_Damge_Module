# GPR 후보 위치 확인 웹뷰어

`../Output/Result/ANM_result.csv`의 이상 후보 126개를
`../../Dam_model/Daecheongdam/daecheongdam_regions_grid5m.gltf` 위에 표시합니다.
뷰어는 현재 CSV의 재산정한 좌표를 읽습니다. 인터넷 연결이나 외부 JavaScript 라이브러리가 필요하지 않습니다.

## 실행

`GPR` 폴더에서 실행한 뒤 <http://127.0.0.1:8771/>을 엽니다.

```bash
python3 MappingReview/serve.py
```

서버에는 Python 표준 라이브러리만 필요합니다. 브라우저는 WebGL2를 지원해야 합니다.
서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.
원격 개발 PC의 서버 IP로 접속할 때는 `--bind 0.0.0.0`을 붙여 실행하거나
IDE에서 8771 포트를 전달합니다.

## 사용

- **댐 전체**: 모델 전체에서 후보의 위치를 확인합니다.
- **GPR 범위 / 선택점 확대**: 측정 영역 또는 선택 후보를 확대합니다.
- **주파수·측선·ID 필터**: 겹치는 후보를 나눠 확인합니다.
- **후보 목록 또는 점 클릭**: XYZ, 최근접 격자, 거리, 해당 측선 Overlay를 보여 줍니다.
- **격자 거리 선**: 선택 후보와 최근접 격자 표면을 연결합니다.
- **가려진 후보 표시**: 모델 뒤에 있는 후보도 표시합니다. 해제하면 실제 가림을 적용합니다.
- **측선 표시**: 주파수·측선 필터에 해당하는 실제 측정 길이의 선을 표시합니다.
- **이전 위치 비교**: 배율 보정 전 위치를 회색 점으로 함께 표시합니다.
- **시작·끝 위치 확인**: 적용한 `NOF_R_0157` 시작점과 `NOF_R_0162` 끝점을 봅니다. 이전 자동 제안선은 체크박스로 따로 표시합니다.
- **시작점 찍기 / 끝점 찍기**: 시작점을 먼저 고르고, 끝점은 시작점과 같은 Z의 mesh 표면에서 선택합니다. 세계 XYZ와 높이 차이를 기록합니다.
- 드래그로 회전하고, 휠로 확대하고, 오른쪽 또는 Shift 드래그로 이동합니다.

흰 점은 선택 후보, 주파수별 색은 다른 후보, 흰 테두리 점은 최근접 격자 표면입니다.
노란 면은 선택 후보의 최근접 격자입니다.

## 시작·끝점 검토

현재 CSV에는 사용자가 전달한 두 점을 적용했습니다. 두 점의 Z는 66.832106811m이고
수평 거리는 26.407940163m입니다. 400MHz LINE_001의 기록 길이 26.663902671m와
약 0.256m 차이가 있어 가로 진행 거리만 0.990400411의 비율로 보간했습니다.
세로 측선 간격·길이와 원자료 `x_m`은 그대로입니다. 다른 가로 측선의 원래 길이 차이도 유지합니다.
새 브라우저에서도 적용한 두 점이 녹색·빨간 점으로 표시됩니다.

모델의 격자 이름은 `NOF_R_0157`입니다. 격자 하나는 영역이므로 번호만으로
실제 시작 좌표를 결정하지 않습니다. 현재 방향에서 이 격자의 중심과
옥외 부대설비의 첫 경계 사이 거리는 약 26.12m이고, 400MHz LINE_001의
기록 길이는 약 26.66m입니다.

`anchor_proposal.json`은 설비 경계에서 기록 길이만큼 되짚은 시작점의
제안입니다. mesh의 평균 수평 방향을 따르며 시작·끝의 Z는 같습니다.
실측 기준점이나 설비와의 실제 여유 거리는 확인되지 않았습니다.
청록·보라 점은 이 제안이고 녹색·빨간 점은 사용자가 직접 지정한 점입니다.

**시작·끝 위치 확인 → 시작점 찍기 → 끝점 찍기 → 좌표 복사** 순서로
다음 수정에 사용할 기준점을 지정합니다. 시작점은 NOF_R_0157, 끝점은 설비 직전의 댐 격자
표면을 선택합니다. 끝점 선택 중 설비를 잠시 숨기며 **옥외 부대설비 표시**로
다시 볼 수 있습니다. 선택은 브라우저에 저장되고 JSON을 복사해서 전달할 수 있습니다.
끝점은 클릭한 격자의 삼각형과 시작점 높이 평면의 교차선에서 가장 가까운 점으로 맞춥니다.
Z만 변경해 mesh를 벗어나지 않으며, 원래 클릭 좌표도 `raw_world_xyz`로 기록합니다.
시작점을 다시 선택하면 이전 끝점은 지웁니다. 이전 버전의 기울어진 지정점은 읽지 않습니다.
서버의 결과 CSV는 이 동작으로 바뀌지 않습니다.

좌표 JSON으로 `Code/fit_start_end.py`에서 지정점 변환을 만듭니다.
예를 들어 `GPR` 폴더에서 실행합니다.

```bash
python3 Code/fit_start_end.py --anchors Data/Calibration/selected_anchors.json \
  --fit-horizontal-endpoints --output Data/Calibration/transform.json
```

`--fit-horizontal-endpoints`는 가로 진행 거리만 두 점에 맞춰 보간하는 옵션입니다.
이 옵션이 없으면 기록 길이와 0.10m 이상 다른 지정점은 오류를 냅니다.
서로 Z가 다른 점이나 mesh 수평 방향과 0.2도 이상 다른 점은 항상 거부합니다.
모델에 지정한 기준점을 적용한 결과이며 현장 측량 정확도를 검증한 좌표는 아닙니다.

## 좌표와 자료

원래 세계 좌표 `(X, Y, Z)`를 glTF 축 `(X, Z, -Y)`로 표시합니다.
큰 절대좌표의 정밀도를 유지하기 위해 모델의 계층 변환을 적용한 뒤
모델 중심을 빼고 GPU에 전달합니다. 후보를 모델 표면으로 옮기지 않습니다.
현재 CSV의 원점은 지정한 NOF_R_0157 점입니다. LINE_001~003은 각각 같은 Z를 유지하고,
LINE_004~012는 경사면의 세로 방향으로 높이가 변합니다.

`proximity_review.json`은 현재 모델과 CSV에 대해 계산한 최근접 삼각형 검토 자료입니다.
후보에서 격자 표면까지의 거리는 약 0.00025~0.01583m이고,
최근접 격자는 `NOF_R_0157`~`NOF_R_0162`의 6개입니다.
이 모델 기준으로 CSV 126행의 `member_name`과 `grid_id`를 기록했습니다.
XYZ는 최근접점으로 이동하지 않으며 가로 Z와 세로 간격을 유지합니다.

`anomalies.json`은 CSV 좌표·Overlay 경로·측선·이전 좌표·검토 정보를 합친 표시 자료입니다.
`model_payload.json`은 glTF 구조와 외부 형상 버퍼 경로를 담습니다.
형상은 원본 모델의 `.bin`을 읽고, 사진 재질은 `textures/`의 최대 1024px
미리보기 JPEG를 사용합니다. 원본 모델과 텍스처는 보존합니다.

## 뷰어 자료 재생성

단위 검토에는 Python 표준 라이브러리, 거리 검토에는 NumPy·Open3D,
빌더에는 Pillow가 필요합니다. `GPR` 폴더에서 순서대로 실행합니다.

```bash
python3 Code/process.py --export-only --work-dir /path/to/existing_detection_results
python3 MappingReview/review_positions.py --apply-grid-mapping
python3 Code/audit_coordinate_units.py
python3 MappingReview/build_viewer.py
```

빌더는 모델과 CSV의 SHA-256이 거리 검토 당시 값과 같은지 확인합니다.
모델이나 CSV를 바꾸면 최근접 거리 검토 자료를 먼저 갱신해야 합니다.
`renderer_base.js`·`controls.js`·`anchor_controls.js`에서 `viewer.js`를 생성하므로
화면 코드는 원본 파일을 수정하고 빌더를 실행합니다.

`verify_viewer.py`는 Selenium·Firefox·geckodriver·Xvfb가 있는 환경에서
실제 WebGL 렌더링, 점 선택, 필터, 48장 Overlay, CSV 좌표 일치, 48개 측선과 이전 위치 비교,
가로 측선 12개의 시작·끝 Z 일치와 끝점의 mesh 수평 교차선 선택,
전달한 기준점의 정확한 반영과 부재·격자 126개 매핑,
모바일 가로 넘침을 확인합니다. 검증 로그와 화면은 `Output` 밖의
`../../unmodified_gpr/GPR_work/viewer_runtime/qa/`에 저장합니다.
