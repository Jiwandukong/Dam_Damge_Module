# Third-party notices

## GPRPy DZT reader

`Code/gpr_gssi_io.py` contains a compact, dependency-free implementation of
the GSSI DZT header and payload parsing algorithm used by GPRPy 1.0.14. This
was done to preserve the established numerical pipeline without requiring
GPRPy's unrelated GUI and VTK dependencies.

- Project: GPRPy
- Source: https://github.com/NSGeophysics/GPRPy
- Upstream revision present in the supplied working archive:
  `69609ea3c3ad26394332c898845c809f4d2be54d`
- License: MIT; the full notice is included in the header of `Code/gpr_gssi_io.py`

The RGPR, Ultralytics/YOLO experiments, pretrained YOLO weights, and the
external GPR-Object-Detection repository found in the development archive are
not used by this demo and are intentionally excluded from the hand-off.
